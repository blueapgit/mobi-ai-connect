# Gemini 계열 에이전트 안내

## 안티그래비티 사용자 안내

마비노기 모바일의 AI 커넥터는 게임 클라이언트와 PC에 설치된 AI 도구를 연결하는 공식 기능입니다. 먼저 [넥슨 공식 AI 커넥터 안내](https://mabinogimobile.nexon.com/Info/Guide/3545322)를 확인하세요.

안티그래비티가 설치되어 있고 로그인되어 있다면, 마비노기 모바일 게임 설정에서 **AI 커넥터 활성화**를 켜세요. 게임이 PC에 설치된 AI 도구를 자동으로 인식해 연결합니다. 이 저장소는 게임 커넥터 자체가 아니라, AI 도구가 게임에 요청을 전달할 때 참고하는 비공식 안내입니다.

이 저장소의 링크를 안티그래비티 채팅에 붙여 넣으면, 에이전트가 공식 안내와 이 저장소의 사용·보안 지침을 함께 확인할 수 있습니다.

터미널 명령을 실행할 때마다 승인 창이 반복되어 불편하다면, Windows 안티그래비티에서 다음과 같이 설정합니다.

1. 안티그래비티 화면 왼쪽 아래의 **Settings**를 누릅니다.
2. 사이드 메뉴의 **General**을 선택합니다. 기본으로 선택되어 있을 수 있습니다.
3. **Global Permissions** 영역의 **Security Preset**을 `Custom`으로 설정합니다.
4. **Terminal Command Auto Execution**을 `Always Proceed`로 설정합니다.
5. 새 세션을 시작해 대화를 다시 시작합니다.

이 설정은 터미널 명령을 자동 실행하므로, 신뢰할 수 있는 프로젝트와 스킬에서만 사용하세요. 게임 작업 외의 명령까지 자동 실행될 수 있으므로, 저장소의 변경 내용과 실행 명령을 확인한 뒤 적용하는 것이 안전합니다.

CLI 실행 파일만 허용하는 와일드카드 규칙은 안티그래비티 버전이나 Windows 권한 설정에 따라 적용되지 않을 수 있습니다. 이 저장소에서는 해당 규칙을 기본 해결책으로 안내하지 않습니다. CLI가 프로젝트 밖에 있어 파일 접근 승인이 별도로 발생하는 경우에만 **Agent Non-Workspace File Access**를 추가로 검토하세요.

### 자주 발생하는 문제

#### 명령마다 승인 팝업이 반복됩니다.

위 경로에서 `Security Preset: Custom`과 `Terminal Command Auto Execution: Always Proceed`를 확인한 뒤 새 세션을 시작하세요. 와일드카드 허용 규칙만 추가하는 방식은 동작하지 않을 수 있습니다.

## 공통 에이전트 원칙

이 저장소의 `shared/` 문서를 먼저 검토한 뒤, 아래 원칙을 해당 에이전트의 사용자 지정 지침에 반영합니다.

- 마비노기 모바일 작업 요청에만 이 지침을 적용합니다.
- 게임 클라이언트의 capabilities를 기준으로 명령과 항목명을 확인합니다.
- 기본적으로 보호된 실행 방식을 유지합니다.
- 사용자가 반복되는 보호 확인을 생략해 달라고 하면 `shared/security.md`의 안내를 먼저 보여주고 명확히 동의받습니다.
- 동의하더라도 검증된 마비노기 CLI만 사용하고, 일반 터미널 명령으로 확대하지 않습니다.
- 한국어 요청 본문은 UTF-8 base64 방식으로 전달합니다.

이 파일은 Gemini 계열 제품의 실제 설정 파일을 자동 설치하는 파일이 아닙니다. 해당 제품의 사용자 지정 지침에 내용을 복사해 적용하세요.
