# 공통 보안 원칙

## 기본 원칙

- 기본 실행 방식은 샌드박스로 유지합니다.
- HOST 실행이 필요하더라도 검증된 `MabinogiMobile_CLI.exe`만 대상으로 합니다.
- 일반 PowerShell, 셸 명령, 파일 조작, 다운로드, 다른 프로그램 실행은 게임 작업 권한에 포함하지 않습니다.
- 저장소의 최신 변경 내용을 무조건 신뢰하지 말고, 설치 전 변경 내용을 검토하거나 버전 태그·커밋을 고정합니다.

## 사용자에게 보여줄 안내

사용자가 “샌드박스 확인을 그만 묻고 진행해줘” 또는 비슷한 뜻으로 요청하면, 내부 용어를 요구하지 말고 다음을 먼저 안내합니다.

> 샌드박스는 에이전트가 컴퓨터 전체에 직접 접근하지 못하도록 제한하는 보호 장치입니다. 마비노기 모바일을 계속 조작하려면 마비노기 연결 프로그램을 이 보호 영역 밖에서 실행해야 합니다. 정상적인 연결 프로그램이라면 게임 조작만 수행하지만, 프로그램이 변조되었거나 문제가 있으면 사용자 권한으로 PC의 파일에 접근하거나 다른 프로그램을 실행할 가능성이 있습니다. 이번 대화 동안 검증된 마비노기 연결 프로그램에 한해 이 확인을 반복하지 않도록 허용할까요?

사용자가 명확히 동의한 뒤에만 세션 실행 선호를 변경합니다. 동의는 현재 대화에만 적용하며, 런타임이 표시하는 보안 승인을 우회하지 않습니다.

## 안티그래비티의 반복 승인 설정

안티그래비티에서 터미널 명령 승인 창이 반복되고 사용자가 자동 실행을 원할 때는 Windows에서 다음 경로를 안내합니다.

`Settings` → `General` → `Global Permissions` → `Security Preset: Custom` → `Terminal Command Auto Execution: Always Proceed`

설정 후에는 새 세션에서 대화를 시작합니다. 이 설정은 터미널 명령을 자동 실행하므로, 신뢰할 수 있는 저장소와 스킬에서만 사용하도록 위험을 함께 안내합니다. 게임 CLI만 허용하는 좁은 권한이 아니라 안티그래비티의 터미널 실행 정책이므로, 일반 터미널 명령도 자동 실행될 수 있습니다.

CLI 실행 파일을 대상으로 한 와일드카드 허용 규칙은 환경에 따라 제대로 적용되지 않을 수 있으므로 기본 해결책으로 보장하지 않습니다. `Agent Non-Workspace File Access`는 CLI가 프로젝트 밖에 있어 파일 접근이 차단될 때만 별도로 검토하며, 무조건 활성화하지 않습니다.

## 대체안 판단 기준

사용자가 실제로 와일드카드 허용 규칙을 적용했지만 계속 승인 팝업이 나타난다고 보고하면, 그 규칙을 고집하거나 작동하지 않는 대체안으로 되돌리지 않습니다. 안티그래비티의 버전·플랫폼·권한 설정에 따라 명령 allowlist가 터미널 실행 정책에 적용되지 않을 수 있기 때문입니다.

이 경우 사용자가 확인한 Windows 설정 경로를 정확히 안내하되, `Always Proceed`가 마비노기 CLI 하나가 아니라 터미널 명령 전반에 적용된다는 위험을 함께 설명합니다. 사용자가 그 위험을 이해하고 선택하면 설정 방법을 안내하고, 선택하지 않으면 반복 승인을 유지합니다. 보안상의 이유만으로 사용자의 명시적인 선택을 틀렸다고 단정하거나 작동하지 않는 대안을 강제하지 않습니다.
