# 마비노기 모바일 Codex 스킬

로컬에 설치된 `MabinogiMobile_CLI.exe`를 사용해 사용자가 명시한 마비노기 모바일 작업을 수행합니다.

## 기본 절차

1. 로컬 게임 AI 커넥터와 CLI가 준비되어 있는지 확인합니다. 준비되지 않았으면 게임 작업을 시도하지 말고 연결 절차를 안내합니다.
2. CLI `status`로 게임 연결을 확인합니다.
3. 세션마다 `capabilities`를 확인하거나 로컬 캐시를 읽습니다.
4. 요청에 맞는 명령과 매개변수는 capabilities에 반환된 스키마만 사용합니다.
5. 채집은 `get_gatherable_items`로 정확한 항목명을 확인한 뒤 `execute_gathering`을 호출합니다.
6. 명령의 `requiresConfirm`가 true이면 실행 직전에 확인을 받습니다.
7. 장시간 실행 명령은 결과가 반환될 때까지 기다립니다.

## 실행 파일

Windows에서는 우선 다음 고정 경로를 사용합니다.

```text
C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe
```

임의의 셸 명령이나 다른 실행 파일로 대체하지 않습니다. 실행 결과의 프로세스 종료 코드와 JSON 응답을 모두 확인합니다.

스킬 설치와 AI 커넥터 연결은 별개입니다. CLI가 없거나 게임 연결이 끊긴 경우 사용자가 게임 클라이언트를 실행하고 게임 설정에서 **MM AI 에이전트 활성화**를 켜도록 안내합니다.

## 자연어 권한 요청

사용자가 “샌드박스 묻지 말고 진행해줘”, “게임 작업은 매번 승인 묻지 마”처럼 반복 확인을 생략해 달라고 하면, `shared/security.md`의 사용자 안내를 먼저 보여주고 명확한 동의를 받습니다. `HOST` 같은 내부 명령을 요구하지 않습니다.

동의 후에도 권한은 현재 대화 동안 검증된 마비노기 CLI에만 적용합니다. 일반 터미널 명령, 파일 조작, 다운로드, 다른 프로그램 실행 권한으로 확대하지 않습니다. 단순한 “계속해”, “빨리 해”만으로는 권한 동의로 해석하지 않습니다.

## 인코딩

한국어가 포함된 명령 본문은 전체 본문을 UTF-8 base64로 인코딩한 뒤 `base64:<값>` 형식으로 전달합니다. JSON 결과의 `\uXXXX` 이스케이프는 정상적인 출력이므로 JSON으로 파싱합니다.

## 중지와 오류

`stop_action`은 채집, 이동, 운반, 자동 플레이 등 중지 가능한 작업을 멈추는 데 사용합니다. `blocked`, `not_in_field`, `tool_missing`, `overweight` 등 오류가 나오면 원문 의미와 사용자가 해결할 조치를 알려줍니다.
