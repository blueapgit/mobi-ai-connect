# Mobi AI Connect

마비노기 모바일 PC 클라이언트와 AI 에이전트를 연결하기 위한 비공식 설정·스킬 모음입니다.

> 이 저장소는 넥슨 및 마비노기 모바일 운영진과 무관한 개인 프로젝트입니다.

## 공식 문서 링크

마비노기 모바일의 공식 AI 커넥터 기능은 게임 클라이언트와 PC에 설치된 AI 도구를 연결합니다. 공식 기능의 자세한 내용은 [마비노기 모바일 AI 커넥터 안내](https://mabinogimobile.nexon.com/Info/Guide/3545322)와 [관련 공지](https://mabinogimobile.nexon.com/News/Notice/3541579)에서 확인하세요.

이 저장소는 넥슨이 제공하는 커넥터나 게임 파일이 아니라, AI 도구에서 사용할 수 있는 비공식 연동 지침을 모아 둔 저장소입니다. 공식 안내에 명시된 지원 AI 도구와 실제 Codex 지원 여부는 각 도구의 제공 상태를 별도로 확인해야 합니다.

## 지원 구성

- `skills/mabinogi-mobile-codex/`: Codex용 스킬
- `agents/gemini/`: Gemini 계열 에이전트의 사용자 지정 지침에 복사해 사용할 안내
- `shared/`: 모든 에이전트가 따라야 하는 공통 명령·보안 원칙

## 필요한 환경

1. 마비노기 모바일 PC 클라이언트를 설치하고 실행합니다.
2. 사용할 AI 도구를 PC에 설치하고 로그인합니다.
3. 게임 설정에서 **AI 커넥터 활성화**를 켭니다.
4. 게임이 설치된 AI 도구를 인식하고 연결할 수 있는지 확인합니다.

이 저장소에는 게임 클라이언트나 실행 파일이 포함되어 있지 않습니다.

게임의 AI 커넥터와 Codex 스킬 설치는 서로 다른 절차입니다. AI 도구가 인식되지 않으면 게임 클라이언트와 AI 도구 설치·로그인 상태를 먼저 확인하세요.

사용자가 별도 설치 경로를 지정하지 않았다면 스킬은 연결된 명령을 먼저 확인하고, 없을 경우 기본 설치 경로 `C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe`를 확인합니다. 다른 위치에 설치했다면 해당 경로를 한 번 알려줘야 합니다.

## Codex 설치

Codex에서 다음과 같이 요청합니다.

```text
GitHub의 blueapgit/mobi-ai-connect 저장소에서
skills/mabinogi-mobile-codex 스킬을 설치해줘.
```

설치 후 다음 대화부터 스킬을 사용할 수 있습니다.

## 권한 안내

기본적으로 에이전트는 샌드박스 보호를 유지해야 합니다. 사용자가 반복되는 확인을 그만 묻고 진행해 달라고 요청하면, 에이전트는 먼저 `shared/security.md`의 설명을 사용자에게 보여주고 명확한 동의를 받아야 합니다.

동의 후에도 권한은 현재 대화와 검증된 마비노기 CLI로만 제한합니다. 일반 터미널 명령이나 다른 프로그램 실행을 허용하는 의미가 아닙니다.

안티그래비티 사용자는 게임 내 **AI 커넥터 활성화**를 켜면 필요한 스킬이 자동 설치됩니다. 터미널 승인 창을 반복해서 보지 않으려면 `agents/gemini/README.md`의 안티그래비티 설정 안내를 참고하세요. `Always Proceed`는 게임 CLI 하나가 아니라 터미널 명령 전반에 적용될 수 있으므로 신뢰할 수 있는 저장소에서만 사용해야 합니다.

## 사용 예시

```text
마비노기 모바일에서 통나무 채집해줘
중지
현재 인벤토리 확인해줘
```
